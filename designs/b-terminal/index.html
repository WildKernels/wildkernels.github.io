install

no computer required

  1. read your kernel string

    uname -r → e.g. 6.1.157-android14. Match the kernel, not the Android version.

  2. flash the anykernel3 zip

    Kernel Flasher, KernelSU manager or recovery. Do not interrupt.

  3. install manager + susfs

    Manager APK from the same release, reboot, add the susfs4ksu module, reboot again.

build flags
susfs on · nomount on · baseband guard on
networking on · ntsync on · bpf/btf on
droidspaces on · performance off
flashing is at your own risk · keep a stock boot.img
