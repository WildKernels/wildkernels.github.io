Three steps, no computer

1

Find your kernel version

Run uname -r. Match the kernel string, not the Android version — a phone on Android 17 can still be on 6.1.x-android14.

2

Flash the matching zip

AnyKernel3 zips flash from Kernel Flasher, the KernelSU manager or recovery. Don't interrupt the flash.

3

Manager, then SUSFS

Install the manager APK from the same release, reboot, add the susfs4ksu module, reboot again.

“Match the kernel version, not the Android version on the phone. That one mistake causes most of the bootloops we see.”

Installation guide

Everything is GPL-3.0 and built in public GitHub Actions: kernel sources, patch series, AnyKernel3 packaging and the release notes are all in the open. Fork it and run the workflow yourself if you want your own flavour.

Flashing is at your own risk. Keep a stock boot.img.
