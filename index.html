02 Inside the build

Everything below is compiled in.
No modules to chase.

Each run is a full GKI build from Android common — features are patched at source level, not bolted on after boot.

01 / ROOT

Your pick of root

KernelSU, KernelSU-Next or BakaSU. FinaSU, SukiSU-Ultra and KowSU on request.

CONFIG_KSU
02 / HIDING

SUSFS, patched in

Kernel-side root hiding with the ptrace leak fix and the Unicode path fix.

CONFIG_KSU_SUSFS
03 / MOUNTS

Metamodule hooks

VFS hooks for module mounts. NoMount is bundled; Mountify also works.

NoMount · Mountify
04 / SECURITY

Baseband Guard

An LSM that refuses writes to critical partitions and device nodes.

CONFIG_BBG
05 / NETWORK

Full network stack

WireGuard, BBRv1/v3, IP Set, IPv6 NAT, conntrack, CIFS, TTL target.

CONFIG_WIREGUARD · IP_SET
06 / TRACING

BTF, eBPF, FUSE-BPF

Matching debug info, so tracing tools and module tooling resolve symbols.

CONFIG_DEBUG_INFO_BTF
07 / PERF

NTSync + tuning

NT-compatible sync primitives, plus the optional scheduler and I/O patches.

common/ntsync
08 / CONTAINERS

DroidSpaces ready

Namespaces and cgroups for Linux containers and chroots on Android.

Droidspaces-OSS

05 Install

Three steps, no PC needed

Full guides →
01

Match the kernel version

Check uname -r or your phone's kernel version. A Pixel 8 running Android 17 is still on 6.1.x-android14 — the androidXX in the kernel string is not your OS version.

6.1.157-android14
02

Flash the zip

Download the AnyKernel3 zip for that version and flavor, then flash it in Kernel Flasher, the KernelSU manager, or recovery. Don't interrupt it.

…-KernelSU-Next-AnyKernel3.zip
03

Manager, then SUSFS

Install the manager APK from the same release, reboot, add the susfs4ksu module and reboot again. The manager should report your new kernel and “Working”.

KernelSU_Next_v3.4.2…apk

Flashing is at your own risk. Back up your boot partition — or at minimum keep a stock boot.img — before you start. Wild Kernels is not responsible for bricked devices or lost data.

06 The projects

One org, four kernel trees

All repositories →

Wild GKI

Generic · 5.10 → 6.12

Built from Google's GKI common trees, so one image covers every device on that kernel line. The main project: 600 images, five lines, three root flavors.

★ 1,764r22629 filesGPL-3.0

OnePlus

Oppo · Realme · per device

Per-device builds from OnePlus OSS sources: HMBIRD SCX schedulers, BBRv3, CAKE/PIE qdiscs, LTO and the memory and I/O patch sets. Maintained by fatalcoder524.

★ 749v2.4.0-r1169 files

Samsung

Galaxy S · A · Tab · One UI 6–8.5

Built from Samsung sources and manifests, with the full feature string in the filename: NM, BBG, BBRv3, DS, NTS, IPv6/IP-set, TTL and UF. Maintained by jimsterino98.

★ 602.3.0-r662 files

Sultan / Pixel

Tensor · Pixel 6–9

kerneltoast's Pixel trees with Wild KSU and SUSFS applied, shipping stock and rooted variants for zuma, zumapro and gs201 side by side.
