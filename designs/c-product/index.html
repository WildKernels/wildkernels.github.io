Inside the build

Everything is in the image, nothing to bolt on after boot

Source-level patches, not userspace tricks. The same features ship in every kernel line.

Root hiding that holds

susfs4ksu with the ptrace leak fix and the non-printable Unicode path fix, patched into the tree.

CONFIG_KSU_SUSFS

Three roots, one release

KernelSU, KernelSU-Next and BakaSU built separately per line, with FinaSU, SukiSU-Ultra and KowSU on request.

CONFIG_KSU

Modules that actually mount

VFS hooks for metamodules. NoMount ships with the release; Mountify works if you prefer OverlayFS.

NoMount · Mountify

Networking kept intact

WireGuard, BBRv1 and BBRv3, IP Set, IPv6 NAT, conntrack, CIFS and the TTL target all compiled in.

CONFIG_WIREGUARD

Tracing that resolves

BTF, eBPF and FUSE-BPF with debug info matching the image, so bpftrace and module tooling find symbols.

CONFIG_DEBUG_INFO_BTF

Containers on Android

DroidSpaces namespaces and cgroups, plus NTSync for Wine and distro work under the hood.

Droidspaces-OSS

Flashing takes three steps and no computer

Download the zip for your kernel version, flash it with Kernel Flasher or your manager, install the matching manager APK and the susfs4ksu module. Keep a stock boot.img — flashing is at your own risk.
