New here? Thirty seconds of context.

A kernel is the part of Android that talks to the hardware. Rooting tools like KernelSU normally need to be built into it, which used to mean compiling a kernel yourself. These are already built — one file per kernel version, with SUSFS included so root stays hidden from apps that check for it, and BBG (Baseband Guard) stopping stray writes to the partitions a bad flash would wreck.

You need: an unlocked bootloader You get: a zip you flash in an app

Three steps, all on the phone

No computer and no toolchain — assuming your bootloader is already unlocked. If you have ever flashed a Magisk module, this is the same level of work.

STEP 1

Check your kernel version

Run uname -r in Termux or any terminal app — or read it from your phone's settings. It looks like 6.1.157-android14; the part before the dash is your build.

STEP 2

Download that build

Pick your kernel version in the list below and take the zip. Choose the root app you already use; if you don't have one yet, take KernelSU-Next.

STEP 3

Flash it, install the app

Flash the zip in Kernel Flasher or your root manager, then install the manager APK from the same release page. Reboot once.

Before you flash

This replaces your boot image. Pull a stock boot.img from your device's firmware and keep it somewhere safe — that file is how you undo a bad flash. If you can't do that yet, stop at step one.

Is this for you?

Being honest saves you a bootloop. This is not the right project for every phone.

Good fit

  • You have already unlocked the bootloader
  • Your kernel version starts with 5.10, 5.15, 6.1, 6.6 or 6.12
  • You want root, or want to keep root hidden
  • You're comfortable flashing a zip

Look elsewhere

  • Your bootloader is locked — nothing here can change that
  • Your kernel is older than 5.10 — those are pre-GKI devices
  • You want one-click root with no risk
  • Your device is carrier-locked

The details, when you want them

What's included in every build

Features are patched into the kernel source, not added afterwards. Every build ships the same set:

  • KernelSU, KernelSU-Next or BakaSU — you choose per file
  • SUSFS root hiding, with the ptrace and Unicode path fixes
  • NoMount metamodule, plus VFS hooks for module mounting
  • Baseband Guard, WireGuard, BBRv3, IP Set, BTF/eBPF, NTSync, DroidSpaces
All kernel lines and Android targets

5.10 → android12, android13 · 5.15 → android13, android14 · 6.1 → android14 · 6.6 → android15 · 6.12 → android16. Six hundred images in total, plus seven manager APKs and the NoMount metamodule.

Building your own variant

Fork the repository and run the Build Kernels workflow. You pick one kernel line, one root flavour and the features you want; GitHub builds it and hands you the zip.

Where to ask for help

The Telegram group is the fast answer, and public so everyone benefits. Include your full kernel string and which manager you installed — those two facts solve most questions.
