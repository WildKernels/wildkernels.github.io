04.2 Before you ask

01

Post your kernel string

The whole thing from uname -r — for example 6.1.157-android14-Wild. Without it nobody can tell which of the 600 images you flashed.

02

Name the manager

KernelSU, KernelSU-Next or BakaSU, plus the version it reports. A mismatched manager looks exactly like a broken kernel.

03

Attach the log

dmesg if it boots, the last screen if it does not. "It doesn't work" cannot be debugged; a bootloop with a log usually can.
