03 Repositories

Four trees, one toolchain.

Kernel source built on AOSP common, OnePlus OSS, Samsung manifests and kerneltoast's Pixel trees. Around them sit the patches, the AnyKernel3 packaging, the metamodules and a couple of tools we needed and nobody else had written.

GKI_KernelSU_SUSFS

The main tree

GKI 2.0 kernels from 5.10 to 6.12 — 5 Android targets, 3 root flavors, every sublevel since 2022. Build Kernels dispatch lets anyone fork and build a variant for themselves.

★ 1,764⑂ 6,264 forks629 files in r22GPL-3.0

OnePlus_KernelSU_SUSFS

Oppo · Realme

Per-device builds from OnePlus OSS: SCX schedulers for SM8750/MT6991, BBRv1/v3, CAKE and PIE, LTO, TTL, IP Set, Unicode bypass fix and Droidspaces containers. Maintained by fatalcoder524.

★ 749⑂ 896v2.4.0-r1

Samsung_KernelSU_SUSFS

Galaxy S · A · Tab

Samsung sources and manifests across One UI 6 through 8.5, with the feature set spelled out in each filename so you know exactly what is compiled in. Maintained by jimsterino98.

★ 60⑂ 562.3.0-r6

Sultan_KernelSU_SUSFS

Tensor · Pixel 6–9

kerneltoast's trees with Wild KSU + SUSFS, shipping rooted and stock variants for zuma, zumapro and gs201 so you can compare without reflashing stock firmware.

★ 189⑂ 142v2.0.0-r12

03.1 Everything else

The parts nobody sees

Live from the GitHub API — stars, forks and the last push for every public repository in the org.

Building your own? Fork GKI_KernelSU_SUSFS and run Build Kernels from the Actions tab — pick one kernel line, one root flavor and only the features you want. The wiki's Configure a Build page explains every input.
